DSA Study Guides & Complexity Cheat Sheets

Reference time/space complexities, data structure properties, and common interview patterns.

Arrays & Dynamic Arrays

Contiguous memory allocation allowing O(1) random access by index.

  • Access: O(1)
  • Search: O(N)
  • Insertion: O(N)
  • Deletion: O(N)
Singly & Doubly Linked Lists

Nodes linked via memory pointers. Fast O(1) insertions at head or tail.

  • Access: O(N)
  • Search: O(N)
  • Insertion: O(1)
  • Deletion: O(1)
Stacks & Queues

LIFO (Last-In-First-Out) and FIFO (First-In-First-Out) linear collections.

  • Push / Pop: O(1)
  • Enqueue / Dequeue: O(1)
  • Peek / Top: O(1)
Trees & Binary Search Trees

Hierarchical node structure with left child < parent < right child.

  • Search: O(log N) avg / O(N) worst
  • Insertion: O(log N)
  • Inorder: Left -> Root -> Right
Graph Algorithms

Vertices connected by directed/undirected weighted or unweighted edges.

  • BFS / DFS: O(V + E)
  • Dijkstra: O((V + E) log V)
  • Floyd-Warshall: O(V^3)
Dynamic Programming

Breaking complex problems into overlapping subproblems with memoization/tabulation.

  • 0/1 Knapsack: O(N * W)
  • LCS: O(M * N)
  • Coin Change: O(N * Amount)
